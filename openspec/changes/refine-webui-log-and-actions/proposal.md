## Why

控制台打磨一轮使用反馈：日志窗口配色固定跟随应用主题，长时间盯盘不舒适且不可调；
空态的「等待输出…」文案无信息量；版本号在概况条与侧栏品牌位重复展示；程序
启停按钮（表格行内悬停按钮 + 详情页头部按钮）素色、分散、两处交互不一致。
本轮把日志阅读体验与危险操作入口统一收拢，降低误触、提升一致性。

## What Changes

- **日志窗口配色三档**：终端黑（默认，黑底白字）/ 纸面白（白底黑字）/ 米黄（护眼，
  `#F2EDDF` 底 `#4A4234` 字）。三档为固定配色，MUST NOT 跟随应用明暗主题切换；
  选择器位于日志查看器工具栏，选择经 localStorage 持久化，缺省为终端黑。stderr
  行的红色区分在全部三档下保留。
- **去掉空态文案**：日志区无输出时不再渲染「等待输出…」等任何占位文案；工具栏的
  行数计数（数据信息）保留。
- **概况条去重版本号**：守护进程概况条删除「版本」格，版本号唯一展示位为侧栏
  品牌位（`v{version}`，双击弹关于对话框，不动）。概况条其余六格与三档断点重排。
- **启停操作菜单化**：程序表格行（全局总览 + App 概况）与进程详情页的行内/头部
  启停按钮**全部移除**，统一为程序操作菜单：
  - **双入口**：程序行/详情页右键，或行尾（详情页头部）悬停浮现的 ⋯ 按钮与键盘
    Menu 键，打开同一菜单；
  - **配色**：菜单项与确认按钮带动作色——启动=绿、重启=琥珀、停止=红（复用状态
    色相 token）；
  - **二次确认**：start 选中即执行（无损，免确认）；stop/restart 选中后同一浮层
    内联变形为「确认停止/重启 xxx？[取消][确认]」，Esc/点外取消，不使用系统弹窗；
  - **反馈**：操作成功/失败结果保持现有可见反馈通道。
- **受牵连更新**：webui 单测（log-viewer / program-table / a11y / prefs 等）与
  xtask e2e playwright 段的选择器与交互脚本同步改为菜单操作。

## Capabilities

### New Capabilities

（无——本变更全部落在既有能力的规范增量上。）

### Modified Capabilities

- `webui-ui`：
  - `日志查看`：新增配色档位选择、持久化与缺省、空态不渲染占位文案的要求；
  - `单程序控制`：操作入口从详情页显式按钮改写为统一程序操作菜单（双入口、内联
    二次确认、动作配色引用视觉规范）；
  - `列表行快捷操作`：行内悬停按钮改写为 ⋯ 按钮 + 右键双入口同一菜单，确认与
    反馈语义保留；
  - `品牌位版本号与关于对话框`：补版本号唯一展示位约束（概况条不重复）。
- `webui-visual-system`：
  - 新增 Requirement `操作动作的配色语义`：启动绿/重启琥珀/停止红的用途边界
    （仅操作菜单项与内联确认按钮，不染名称与状态文字）；
  - 新增 Requirement `日志窗口配色档位`：三档固定配色的定义、stderr 着色保留与
    「不跟随应用主题」约束。

## Impact

- **纯前端改动**：`/v1`、`/api` 后端接口与 WS 帧零变更；守护进程 Rust 侧不动。
- 代码面：
  - `webui/src/components/log-viewer.ts`（三档配色 + 空态清理）
  - `webui/src/lib/prefs.ts`（新增日志配色偏好，注释「resist feature creep」同步修订）
  - `webui/src/components/overview-bar.ts`（删版本格 + 三档断点网格重排）
  - `webui/src/components/program-table.ts`、`webui/src/views/program-detail.ts`
    （撤行内/头部按钮，接菜单入口）
  - 新增 `webui/src/components/action-menu.ts`（程序操作菜单：右键/⋯/键盘三入口
    同一组件，内联确认状态机）
  - `webui/src/styles/tokens.css`（三档日志配色常量与动作色用途，若需新 token）
- 测试面：webui 单测更新 + 新增（action-menu 状态机、prefs 新偏好、log 三档）；
  `xtask` e2e playwright 段从点行内按钮改为右键/⋯ 菜单交互。
- 不在范围：App 概况「移除应用」按钮与 Apply 流程、侧栏品牌位与关于弹窗、
  凭据门、树导航。
